# Авто-Подтверждение Присутствия (МТС Линк & Яндекс Телемост)

Универсальное расширение для браузеров **Google Chrome**, **Яндекс Браузер**, **Microsoft Edge**, **Opera** и **Mozilla Firefox**, которое автоматически нажимает кнопки подтверждения присутствия на лекциях, вебинарах и встречах в **МТС Линк (Webinar.ru)** и **Яндекс Телемост (telemost.yandex.ru / .com)**.

---

## 🌐 Поддерживаемые сервисы

- **МТС Линк / Webinar.ru** (`*.mts-link.ru`, `*.webinar.ru`)
- **Яндекс Телемост** (`telemost.yandex.ru`, `telemost.yandex.com`)

---

## 🚀 Инструкция по установке в Google Chrome / Яндекс.Браузер / Edge / Opera

1. Откройте ваш браузер (Chrome / Yandex / Edge).
2. Перейдите на страницу управления расширениями:
   - В **Google Chrome**: `chrome://extensions/`
   - В **Яндекс Браузере**: `browser://extensions/`
   - В **Microsoft Edge**: `edge://extensions/`
3. Включите **«Режим разработчика»** (Developer mode) в верхнем углу страницы.
4. Нажмите кнопку **«Загрузить распакованное расширение»** (Load unpacked).
5. Выберите папку с расширением.
6. Расширение установлено и готово к работе!

---

## 🦊 Инструкция по установке в Mozilla Firefox

1. Откройте Firefox и перейдите по адресу `about:debugging#/setup`.
2. Нажмите слева **«Этот Firefox»** (This Firefox).
3. Нажмите кнопку **«Загрузить временное дополнение...»** (Load Temporary Add-on...).
4. Выберите файл `manifest.json` в папке с расширением.

---

## ⚙️ Возможности

- **Универсальный автокликер**: мгновенно находит всплывающие окна контроля активности и нажимает «Я здесь», «Подтвердить», «Продолжить звонок», «Вернуться в звонок» и др.
- **Звуковой сигнал**: воспроизводит приятный короткий звук при каждом успешном подтверждении.
- **Экранный бейдж**: выводит стильное плавающее уведомление на странице.
- **Счетчик откликов**: сохраняет количество автоматически пройденных проверок.
- **Удобный Popup**: включает и выключает функции в 1 клик.
